【ACE COMBAT 8 + UEVR — 中文 HUD / 菜单修复】

■ 问题
用 UEVR 把 ACE COMBAT 8 转成 VR 后，飞行 HUD 和所有菜单在头显里完全不显示。

■ 修复脚本
https://github.com/【这里填仓库地址】

■ 用法（3 步）
1. 把 ac8_ui_fix.lua 放进 %APPDATA%\UnrealVRMod\AceCombat8\scripts\
2. 游戏里按 Insert → LuaLoader → Run script
   （游戏已经在运行的话，点 Reset scripts 也行）
3. HUD 和菜单就出来了；想让 UI 跟随视角，在 UEVR 里开 UI follows view

■ 说明
· 只改运行时内存，不动游戏文件，重启游戏完全恢复
· 不需要重新编译 UEVR，不需要装别的插件
· 已知未解决：俯仰梯（攻角表）和机炮准星仍不显示。
  它们走的是游戏另一套 3D HUD 路径（渲染成纹理后由世界组件绘制），
  不属于普通 UI 控件，脚本层面碰不到，需要从 UEVR 侧解决。
